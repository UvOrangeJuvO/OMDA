# curated-omda Genre package

Non-demo, human-reviewed curated Genre taxonomy for OMDA v0.1 (G3-007).

- **Content**: 5 real Genre records (Ambient, Bebop, Krautrock, Tuareg Music, IDM).
- **License (data)**: curated factual taxonomy — CC0-1.0. The data license is
  separate from any code license (ADR-0002 D1). MusicBrainz-related enrichment
  at run time follows MusicBrainz's own terms.
- **Provenance**: origin_url (Wikipedia index), retrieved_at, dataset_version
  recorded in `source.yaml`; the reviewed source registry
  (`data/sources/registry.jsonl`) is the trust anchor.
- **demo**: false — this is a production-eligible package, not a sample.
